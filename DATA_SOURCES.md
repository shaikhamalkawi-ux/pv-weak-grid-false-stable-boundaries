# External data sources and their roles

These published source datasets were used for narrowly defined supplementary investigations, **not** as field validation of the benchmark weak-grid stability boundary:

| Dataset | DOI | Role |
|---|---|---|
| NREL/OEDI PVDAQ public datasets | [10.25984/1846021](https://doi.org/10.25984/1846021) | Measured irradiance operating-level input stress |
| Oahu Solar Measurement Grid | [10.7799/1052451](https://doi.org/10.7799/1052451) | Spatially varying measured irradiance input stress |
| OEDI/IBR Transient Data Library | [10.25984/2228281](https://doi.org/10.25984/2228281) | Measured inverter admittance interaction-root diagnostics |
| NREL PV Inverter Experimental Dataset Version 2 (100 Percent Power) | [10.7799/2205350](https://doi.org/10.7799/2205350) | Separate 20-kW inverter operating-envelope checks |

Original third-party measurements have **not** been uploaded to this repository. Redistribution and licensing terms must be assessed at the original sources before any data mirror is created.
