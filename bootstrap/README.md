# 89-case descriptive profile-cluster bootstrap — release status

The V24 calculation uses 10,000 replicates (NumPy seed 20260917). Whole profile pairs are resampled within the two stochastic families; 21 capacitance and four PLL cases remain fixed. The frozen 2.5% guard has no failures on the 89 evaluated held-out boundaries, but a separate localized-cloud transfer challenge requires a 4.577% correction.

The verified runnable Python script and frozen 89-case CSV are prepared for a public-safe release, but **are not yet present in this GitHub directory**. A source archive, before its publication, must not be claimed to be reproducible from this GitHub page.

This is a descriptive fixed-set resampling sensitivity calculation, not a population confidence interval or probability guarantee.
